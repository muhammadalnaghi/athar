# WM030: prospective certified purchases

Complete a narrow production slice: a supported bank-specific completed purchase with an explicit positive transaction amount and source-stated date counts once, with or without categorization. Generic first-amount extraction, transfers, income, refunds, holds and missing-date shapes do not receive purchase authority.

An opaque process-lifetime session is captured before suspension. Backup whole-store replacement invalidates outstanding sessions inside its Room transaction before mutation. The core:data facade independently verifies typed posted support, purchase kind/direction, SMS/notification namespace, literal currency, exact stored monetary value/date, source binding, fresh transaction id/timestamp and untouched pending state. Existing user decisions and edits are never overwritten. Canonical admission and the single existing-query status projection share one Room transaction; any projection failure rolls both back. Replays do not reapprove historical rows, and readers never sum canonical and legacy copies. The existing engine remains unchanged behind the facade.

The local rollout remains off by default. A parent-only explicitly opted-in native harness enables it temporarily, exercises the actual production graph and restores the flag unconditionally. Restore fencing covers certified admission/projection; this slice does not claim fencing of every older legacy ingestion/audit operation. Refused or unsupported shapes remain pending and do not imply a payment is false. No historical mass confirmation, schema change, network operation, private upload, phone operation or release is authorized by this slice.

Acceptance requires focused app mapping tests, real Room source/economic/edited-row/stale-session/rollback/replay tests, both debug builds and actual own-message native replay plus a visible user journey. Green parser metadata or an unexecuted native class is not acceptance. Any private report contains aggregates only; originals and the authenticated baseline are preserved.
