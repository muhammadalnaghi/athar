# WM033 — Saved dated position on Today

## Surface and outcome

Operate mode: make the user's saved dated position visible on Today without asking for the same inputs again. Preserve the existing Today landmark, recorded-account balance, income/expense scope, pending tray, three destinations, Plan001 and family investments. This is an additive summary of declared inputs, not a dashboard redesign or a claim of verified whole wealth.

## Ownership and state

The encrypted saved-financial-plan repository remains the sole writer/source. Plan retains its current balance_anchor v1 writer and editor. A read-only core-data adapter exposes each valid saved document separately through a domain repository; it never adds overlapping documents or converts currencies. Decode and exact aggregation run off Main. Malformed, oversized and unsupported documents stay untouched in storage and do not become zero-valued summaries. Keep decimal projection magnitude bounded before arithmetic or rendering.

Today selects one dated document containing its literal display currency, ordered by as-of date, update time and identity. The immutable UI projection contains document identity/revision, title, date and exact net money. No position value is added to transaction flow or recorded-account balances. A missing document or absent currency produces no summary, not zero wealth. Free-text ownership is not interpreted as financial shares.

## Acceptance

Verify liability-only net sign, currency separation, typed versions/fields, unsupported documents and deterministic latest selection with focused JVM cases. Retain all existing Today testcase identities. After a signed unseeded update on the owned API35 emulator, show the previously saved QA Position032 revision2 as declared input with the exact negative SAR amount and its date, without re-entering or rewriting it. Inspect the native screenshot and read back the installed APK hash. Phone acceptance, true liquid balances, widget freshness and complete benchmark acceptance remain separate gates.
