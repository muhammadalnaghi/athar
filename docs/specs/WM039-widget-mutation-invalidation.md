# WM039 — refresh widgets after successful financial mutations

Goal: remove the actual stale-widget counterexample observed after restoring the captured encrypted baseline. The widget kept its larger pre-restore month flow while Today and Room had already returned to the original two records. Preserve exact currency scope, opt-in placement, encrypted Room ownership, existing widget layout and the original backup/CAS implementations.

Reuse the existing WidgetRefresher interface. Regular saved-plan writes use its conflated queue; a whole-backup restore awaits the immediate Glance update enqueue before returning, so immediate process completion cannot drop a delayed request. Notify only after successful public backup imports and saved-plan saves/deletes, never before commit or after a rejected/cancelled mutation. Small repository decorators delegate crypto, validation, transactions and returned revisions unchanged. Export/read operations do not request refresh. There is no new financial authority, schema, data cache, network request or dependency.

Within a live Glance session, an update must also reload its application snapshot: a one-shot produceState with no changing key can otherwise retain old data. Expose only an opaque in-process invalidation token, observed by all three widget renderers. The existing updater changes this token before requesting Glance updateAll. Cancellation still propagates; loading/failure remain distinct from known zero. Store no financial values in this signal or outside the existing encrypted repositories.

Acceptance: executed assertion RED then GREEN for post-success-only notification, failure/cancellation/no-read notification and unchanged returned revisions. Verify notification changes the renderer key. Build both unseeded debug flavors and the current app instrumentation APK. Native acceptance checks a real money mutation and reversal/restore on the owned AVD, observed current widget amounts and unchanged original baseline. Do not substitute a manual pin/forced broadcast for the mutation notification under test. Full revision-bound encrypted last-good caches, all widget sizes and phone/performance acceptance remain excluded.
